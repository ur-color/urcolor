## Unreleased

### Added

- Initial release: headless Angular directives and signal stores — color area,
  slider, field, swatch, swatch picker, wheel, triangle and ring — with the same
  unstyled, composable shape as the Vue, React and Svelte bindings.
- WebGL gradient rendering with a CPU sampler fallback, keyboard navigation and
  ARIA wiring throughout.
